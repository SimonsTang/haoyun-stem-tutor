## Quick Start

```bash
# Via ClawHub (recommended)
clawhub install haoyun-stem-tutor

# Or manually — copy this skill folder to your OpenClaw workspace skills/
cp -r haoyun-stem-tutor/ ~/.qclaw/skills/
```

Restart OpenClaw and say **"学长，这道数学题怎么做"** or **"帮我讲一下这个物理概念"**
